## 章節用意

前面章節是以「教學」的方式逐一介紹變身檔的各項指令，本章改以「格式規格」的角度，把變身檔編碼檔(`list.spr`、`list.spz`、`TW13081901.txt`)的語法一次整理成表，並以一份實際的 `TW130819011.txt` 做統計驗證，方便之後撰寫解析器、轉檔工具或動畫播放器時查閱。

## 檔案總覽

編碼檔為純文字檔，結構是「檔頭」加上依序排列的多個「變身段落」：

```plain
22536 0 41210                                  ← 檔頭
#0 312=3225                                    ← 變身段落 #0 開始
	0.(1 4,0.0:4<479 0.1:4 0.2:4<478 0.3:4)    ← 動作行
	1.(1 7,0.0:0 16.0:3 16.1:3 ...)
	...
	101.(3226)                                 ← 特殊行
	102.(6)
	105.(1 6262)
#1 312=3227                                    ← 變身段落 #1 開始
	...
```

* 每個動作行、特殊行都以一個 `Tab` 開頭，變身段落起頭行則以 `#` 開頭、沒有縮排。

* 本檔的變身段落共 `22536` 個，編號 `#0` ~ `#22535`，與檔頭第一個數字一致。

## 檔頭

```plain
22536 0 41210
```

| 欄位 | 說明 |
| --- | --- |
| 第 1 個數字 | 變身編碼總數 **[已驗證]**，編號 `#0` ~ `#(總數-1)` 不可缺號，詳見[初步說明與規則](./112_變身檔-初步說明與規則.md) |
| 第 2、3 個數字 | 用途未知(此檔為 `0` 與 `41210`)，原章節同樣標示「暫時不知用途」 |

## 變身段落

```plain
#0 312=3225
#61 320=3213 Knight        ← 舊版寫法，帶有名稱
#2 1
```

格式為：

```plain
#變身編號 圖檔數量[=圖檔編號] [名稱]
```

* `變身編號`：`#` 開頭的變身檔編號，也就是 `gfxid`。

* `圖檔數量`：此變身可使用的 `spr` 圖檔總數 **[已驗證]**。例如 `312=3225` 表示可使用 `3225-0.spr` ~ `3225-311.spr`。

* `=圖檔編號`：指定 `spr` 圖檔改用哪一組編號 **[已驗證]**。

  * 本檔 22536 個段落中，有 `=` 的有 `4681` 個，沒有 `=` 的有 `17855` 個。

  * 沒有 `=` 時，推測圖檔編號就等於變身編號 **[推測]**：[動畫圖檔 spr 基礎了解說明](./111_動畫圖檔_spr_基礎了解說明.md)的 `#240` 範例沒有 `=`，使用的正是 `240-0.spr`。

* `名稱`：舊版編碼檔會寫英文敘述，本檔已省略。

## 動作行

```plain
	動作編號.[動作名稱](方向旗標 影格數,影格 影格 影格 ...)
```

以 `0.(1 4,0.0:4<479 0.1:4 0.2:4<478 0.3:4)` 為例：

| 部分 | 說明 |
| --- | --- |
| `0` | 動作編號，對照[動作編碼清單](./113_變身檔-格式與編碼基礎.md#spr-action-list) |
| `.` 與動作名稱 | 動作名稱可省略。本檔大多省略，僅少量保留(如 `104.attr(8)`) |
| `1` | 方向旗標：`1` 有方向性、`0` 無方向性 **[已驗證]** |
| `4` | 此動作使用的影格(圖片)總數 |
| `,` | 分隔「頭部資訊」與「影格清單」 |
| 影格清單 | 以半形空白分隔，見下節 |

* 有方向性(`1`)的動作，只需寫面向左上方的基準方向，其餘 7 個方向由客戶端依 `spr` 檔案序號延伸 **[已驗證]**，對應關係為：

```plain
3213-0.spr  → 面向左上方(基準)
3213-1.spr  → 面向正上方
 ...
3213-7.spr  → 面向正左方
```

* 實際資料中，動作的 `spr` 序號通常是 `8` 的倍數(如 `16.0`、`24.0`、`232.0`)，與「每個動作組佔 8 個方向檔」的規則相符 **[推測]**。

* 同一個變身內，「動作編號 + 動作名稱」重複且內容不同，客戶端會 `Lineage 已經停止運作` **[已驗證]**。

  * 但本檔中同一個 `#` 段落內動作編號重複出現的情況不少(合計 1,524 次)，常見於無方向性(`0`)的動作，一個方向寫一行。這與上述規則是否衝突，需另行實測 **[待確認]**。

## 影格

```plain
圖檔序號.圖片序號:停留時間[修飾符號]
```

以 `24.2:3]214` 為例：

| 部分 | 說明 |
| --- | --- |
| `24` | `spr` 圖檔序號，即 `圖檔編號-24.spr` |
| `2` | 該 `spr` 內的第 `2` 張圖片，即 `圖檔編號-24-002.bmp` |
| `:3` | 停留 `3` 單位時間，`1` 單位 = `1 / 24` 秒 **[已驗證]** |
| `]214` | 修飾符號，見下節 |

* 停留時間可為 `0`，如 `16.0:0`、`0.0:0]5573`，搭配 `]` 時是不佔時間、只觸發效果的影格 **[推測]**。

* 一個影格可以掛多個修飾符號，如 `8.2:8[297]1160`、`0.0:4[34!`。本檔有 `27,673` 個影格帶有兩個以上的修飾符號。

## 影格修飾符號

| 符號 | 後接數字 | 說明 | 本檔出現次數 |
| --- | --- | --- | ---: |
| `!` | 否 | 執行到該影格時，目標出現被打動作與被打聲音(命中點)。移除後，目標不會有受擊反應，射出的箭與魔法也不會命中 **[已驗證]** | 26,630 |
| `[` | 是 | 執行到該影格時播放該編號的聲音檔，路徑為客戶端 `Sound\` **[已驗證]** | 32,311 |
| `<` | 是 | 執行到該影格時播放該編號的聲音檔 **[已驗證]**。與 `[` 的差異未見說明 | 84,502 |
| `]` | 是 | 執行到該影格時，套用另一個變身編碼的效果，例如 `]214` 即 `#214`。被套用的圖檔不能再套圖檔 **[已驗證]** | 3,736 |
| `>` | 否 | 無數字。原章節標示「未知」，常成對出現在呼吸、走路等動作的奇數格，如 `0.1:8> 0.3:10> 0.5:8>` | 1,217 |
| `^` | 是 | 原章節未列出。出現在 `3.(0 …)` 呼吸/待機動作，如 `0.1:4^3164`，數字範圍從 3 位數到 4 位數 | 143 |
| `{` | 是 | 原章節標示「未知」。出現位置如 `96.0:5{200` | 6 |
| `}` | 是 | 原章節標示「未知」。出現位置如 `104.8:6}100` | 4 |

> 註：`<` 與 `[` 的聲音編號範圍相同。`^`、`>`、`{`、`}` 的功能尚無來源佐證，詳見[待確認事項](#待確認事項)。

## 語法整理

以下是整份檔案的非正式文法(EBNF 風格)：

```plain
檔案        = 檔頭 CRLF { 段落 }
檔頭        = 總數 SP 數字 SP 數字
段落        = "#" 編號 SP 圖檔數量 [ "=" 圖檔編號 ] [ SP 名稱 ] [ TAB ] CRLF { 行 }
行          = TAB 編號 "." [ 名稱 ] "(" 內容 ")" CRLF
內容(動作)   = 方向旗標 SP 影格數 "," 影格 { SP 影格 }
內容(屬性)   = 數值 { SP 數值 }           ; 無逗號與影格
影格        = 圖檔序號 "." 圖片序號 ":" 停留時間 { 修飾 }
修飾        = "!" | ">" | ( "[" | "<" | "]" | "{" | "}" | "^" ) 數字
```

* 變身段落起頭行的結尾可能有 `Tab`。

* 影格數與影格清單的實際個數不一定相等，是否以影格數為準需另行驗證。

## 解析時的注意事項

* **換行**：檔案是 `CRLF`，逐行解析時要去掉結尾的 `\r`。

* **無逗號的括號**：`105.(1 6262)`、`102.(6)` 沒有逗號，不能套用動作行的規則。依編號分流比較穩妥。

* **含逗號的特殊行**：`100.(1 -2,0,2,0)` 的括號內有逗號與負數，也不是影格。

* **動作名稱可有可無**：同一份檔案裡 `104.(8)` 與 `104.attr(8)` 並存，名稱含空白(如 `alt attack`)時也要處理。

* **不合規的影格**：本檔有約 320 個影格不符合 `圖檔.圖片:時間` 的格式，來自 `109.(2 -1)`、`100.(…)` 這類含逗號的特殊行被誤判，不是資料錯誤。

* **編碼檔不含圖檔**：編碼檔只描述播放順序與時間，要顯示畫面還需要對應的 `.spr` 檔，見[動畫圖檔 spr 基礎了解說明](./111_動畫圖檔_spr_基礎了解說明.md)。
