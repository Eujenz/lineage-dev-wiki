## 章節用意

在開始後續的核心修改文章前，請先具備非常非常基礎的程式語能能力，以下這邊提供一些我覺得還不錯的新手練習/教學網站。

記住在還沒有對程式語言培養出興趣前，不建議去購買線上課程，因為這些課程的價格其實都不便宜，建議還是先透過教學網站，進行簡單的學習，慢慢培養興趣。
如果喜歡翻實體書本的部分，是可以在線上查詢電子書試看，挑選覺得適合自己排版或是內容後再進行購買。

像我自己本身是喜歡直接去書局，直接翻閱挑選幾本後再做決定。​‌‌‌​​​​​‌‌‌​​‌​​‌‌​‌​​‌​‌‌‌​‌‌​​‌‌​​​​‌​‌‌‌​‌​​​‌‌​​‌​‌​​‌​‌‌​‌​‌‌​‌‌​​​‌‌​‌​​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌​​​​‌​‌‌​​‌‌‌​‌‌​​‌​‌​​‌​‌‌​‌​​‌‌​​‌​​​‌‌​​​​​​‌‌​​‌​​​‌‌​​​‌​​‌‌​​​​​​‌‌‌​​​​​‌‌​​​​​​‌‌​‌‌‌​​‌​‌‌​‌​‌‌‌​​​​​‌‌‌​​‌​​‌‌​‌​​‌​‌‌‌​‌‌​​‌‌​​​​‌​‌‌‌​‌​​​‌‌​​‌​‌​​‌​‌‌​‌​‌‌​‌‌​​​‌‌​‌​​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌​​​​‌​‌‌​​‌‌‌​‌‌​​‌​‌​​‌​‌‌​‌​​‌‌​​‌​​​‌‌​‌‌​

## 教學網站

不管是學習一門程式語言還是技術，最好的學習網站首選就是「官方」的教學或是文件。

* Java
[The Java™ Tutorials](https://docs.oracle.com/javase/tutorial/)

* MySql
[MySql - Documentation](https://dev.mysql.com/doc/)

有時候官方的教學可能沒有點出其重點或是問題解答，這時候可以查看其他的教學網站或是透過搜尋找到相關的文章。

* 菜鳥教程
「菜鳥教程」網是我無意間發現的網站，網站涵蓋很多程式語言的基礎教學，像是`HTML / CSS`、`JavaScript`、`資料庫`…等等，
由於是「簡體中文」所以對於看的懂的我，覺得非常輕鬆快速。
[runoob.com - Java 教程](https://www.runoob.com/java/java-tutorial.html)
[runoob.com - SQL 教程](https://www.runoob.com/sql/sql-tutorial.html)
[runoob.com - MySQL 教程](https://www.runoob.com/mysql/mysql-tutorial.html)

* w3schools
算是滿早期就有的程式語言教學網站，全網英文<有像有中文網>，透過簡單的例子與線上互動模式，可以輕鬆在線上動手做練習。
[w3schools - Java Tutorial](https://www.w3schools.com/java/default.asp)
[w3schools - SQL Tutorial](https://www.w3schools.com/sql/default.asp)

* tutorialspoint
該網站是我在學習`openresty`的時候發現的網站，我覺得排版和內容都還不錯。
[tutorialspoint- Java Tutorial](https://www.tutorialspoint.com/java/index.htm)
[tutorialspoint- SQL Tutorial](https://www.tutorialspoint.com/sql/index.htm)

* J.J.’s Blogs 的技術「學習」「筆記」部落格
最後不免俗推薦一下自己的部落格，各式各樣的教學和筆記，如果不嫌棄可以參閱看看。謝謝。
[J.J.’s Blogs](https://morosedog.gitlab.io/categories/)
